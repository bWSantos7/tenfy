# Prints do tutorial interativo

Coloque aqui os prints exibidos em cada passo do tutorial (componente
`InteractiveTutorial`). Se um arquivo não existir, o passo cai para o ícone.

Arquivos esperados (nomes referenciados em `src/data/helpContent.tsx`):

| Arquivo                      | Passo                                   | Perfil        |
|------------------------------|-----------------------------------------|---------------|
| `bem-vindo.png`              | Boas-vindas                             | todos         |
| `cadastrar-dependente.png`   | Cadastrar dependente (aba Perfil)       | responsável   |
| `alternar-dependente.png`    | Alternar entre dependentes              | responsável   |
| `torneios.png`               | Torneios compatíveis                    | todos         |
| `acompanhar-torneio.png`     | Acompanhar torneio (estrela)            | todos         |
| `agenda.png`                 | Agenda                                  | todos         |
| `inscricoes.png`             | Inscrições                              | todos         |
| `resultados.png`             | Rankings e resultados                   | todos         |
| `perfil-esportivo.png`       | Perfil esportivo                        | todos         |
| `configuracoes.png`          | Configurações da conta                  | todos         |
| `ajuda.png`                  | Precisa de ajuda? (ícone "?")           | todos         |

Dicas:
- Use a mesma proporção/resolução entre os prints (ex.: todos do desktop).
- Pode anotar destaques (retângulo/seta) direto na imagem.
- PNG ou JPG; o card usa `object-contain`, então qualquer proporção encaixa.
